# Security Policy

## Supported Versions

Security updates are provided for the latest published version of this package.
Please update to the newest release before reporting a potential vulnerability.

## Reporting a Vulnerability

Please do not open public GitHub issues for security vulnerabilities.
Instead, report vulnerabilities privately by email:

- dev@buddies-dev.de

To help us investigate quickly, please include:

- A clear description of the issue
- Steps to reproduce
- Potential impact
- A proof of concept, if available
- Your contact information for follow-up

## What to Expect

After receiving your report, we will:

- Confirm receipt as soon as possible
- Investigate and validate the report
- Work on a fix and coordinate responsible disclosure
- Credit you for the report, if you want attribution
