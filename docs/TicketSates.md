# Ticket States Operations

## Get Ticket States

Retrieve a list of all ticket states.

**Parameters:**

- **API Token** (required)

## Create Ticket State

Create a new ticket state.

**Parameters:**

- **API Token** (required)
- **Name** (required)
- **Image**
- **Wait State**
- **Rank**
- **Active**

## Update Ticket State

Update an existing ticket state.

**Parameters:**

- **API Token** (required)
- **Ticket State ID** (required)
- **Name** (required)
- **Image**
- **Wait State**
- **Rank**
- **Active**

## Delete Ticket State

Delete a ticket state.

**Parameters:**

- **API Token** (required)
- **Ticket State ID** (required)
