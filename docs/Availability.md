# Availability Operations

## Get Availability

**API Endpoint:** GET /api/v1/availability

Fetches availability infos

**Parameters:**

- **Employee IDs (Comma Separated)** (required)

## Get Availability Types

**API Endpoint:** GET /api/v1/availability/types

Returns the configured catalog of availability types used to mark an employee as unavailable on a given day (for example `Urlaub`, `Krank`, `Feiertag`, `Fortbildung`).
