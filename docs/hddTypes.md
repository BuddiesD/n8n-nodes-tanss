# HDD Types Operations

## Create HDD Type

**API Endpoint:** POST /api/v1/hddTypes

Create a new HDD type.

**Parameters:**

- **ID**
- **Name**

## Delete HDD Type

**API Endpoint:** DELETE /api/v1/hddTypes/{id}

Delete an HDD type.

**Parameters:**

- **HDD Type ID** (required)

## Get HDD Types

**API Endpoint:** GET /api/v1/hddTypes

Retrieve a list of all HDD types.

**Parameters:**


## Get HDD Type

**API Endpoint:** GET /api/v1/hddTypes/{id}

Retrieve a specific HDD type by its ID.

**Parameters:**

- **HDD Type ID** (required)

## Update HDD Type

**API Endpoint:** PUT /api/v1/hddTypes/{id}

Update an existing HDD type.

**Parameters:**

- **HDD Type ID** (required)
- **ID**
- **Name**
