# Mails Operations

## Test SMTP Settings

**API Endpoint:** POST /api/v1/mails/test/smtp

Test SMTP email settings by sending a test email.

**Parameters:**

- **Receiver** (required)
- **SMTP Address**
- **SMTP Host**
- **SMTP User**
- **SMTP Password**
- **SMTP Auth**
- **SMTP Encryption Type**
- **SMTP Sender Name**
