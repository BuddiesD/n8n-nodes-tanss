# Search Operations

## Global Search

**API Endpoint:** PUT /api/v1/search

Perform a global search across multiple areas.

**Parameters:**
- **API Token** (required)
- **Use Raw Filter JSON (Optional)**
- **Areas**
- **Query**
- **Company Max Results**
- **Employee Max Results**
- **Employee Company ID**
- **Employee Inactive**
- **Employee Categories**
- **Employee Callbacks**
- **Ticket Max Results**
- **Ticket Preview Content Max Chars**
- **Ticket Company ID**
