# Employees Operations

## Get Technicians

**API Endpoint:** GET /api/v1/employees/technicians

Retrieve a list of all technicians.

**Parameters:**
- **API Token** (required)
- **Freelancer Company ID**

## Create Employee

**API Endpoint:** POST /api/v1/employees

Create a new employee.

**Parameters:**
- **API Token** (required)
- **ID**
- **Name**
- **First Name**
- **Last Name**
- **Salutation ID**
- **Department ID**
- **Room**
- **Telephone Number**
- **Email Address**
- **Car ID**
- **Mobile Phone**
- **Initials**
- **Working Hour Model ID**
- **Accounting Type ID**
- **Private Phone Number**
- **Active**
- **ERP Number**
- **Personal Fax Number**
- **Role**
- **Title ID**
- **Language**
- **Telephone Number Two**
- **Mobile Number Two**
- **Restricted User License**
- **Birthday (YYYY-MM-DD)**
- **Company Assignments**
- **Assignment Company ID**
